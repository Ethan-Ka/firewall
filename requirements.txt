# The collector's dependencies, in full.
#
# There are none, and that is worth keeping. api/collect.py reaches
# Broadcastify, a transcription API and Redis over urllib, signs its own JWT
# with hmac, and the parser it hands the words to has imported nothing but
# difflib and re since it was written. So a cold start is the runtime and the
# source: no wheel to fetch, no version to pin, nothing that can break because
# something upstream shipped on a Tuesday.
#
# The heavy half of this program -- faster_whisper, torch, 480MB of model
# weights -- lives in pyproject.toml, which Vercel does not read. That split is
# the whole point: what is missing here is exactly what could never have run
# here anyway, and it is missing on purpose rather than by omission.
